SHARKCODE 0.2.50 -> 0.2.52 (накопительный патч)

Включает обновления 0.2.51 и 0.2.52.
Распакуйте ZIP в каталог, СОДЕРЖАЩИЙ папку SHARKCODE, с заменой файлов.
Основа: SHARKCODE 0.2.50. Если уже стоит 0.2.51, можно использовать патч 0.2.51 -> 0.2.52.
Исходный код, без пересборки EXE.

Накопительный патч собран последовательным наложением: сначала 0.2.51, затем 0.2.52.
Он не включает удаление старых файлов: исходные патчи также не содержат манифеста удаления.
