присваивание можно выполнять не только через a = 1. есть еще пару фишек. например, множественное:
a = b = 1
иногда это можно быть полезно (Если 2 переменные должны иметь один вид), но используйте с умом.
"обмен  значениями"
можно так менять или присваивать значение несколько раз за строку. например
a, b = 1, 2
но у этой штуки есть более интересное применение:
a, b = b, a
согласитесь, это куда удобнее чем что-то вроде
a, b = 1, 2
buffer = a
a = b
b = buffer
можно сколько угодно
a, b, c, d = d, a, c, b
и наконец явное указание типа
a: int = 10
это явное указание что это int. правда, это ничего особо не меняет, но сильно повышает читаемость кода вдальнейшем
