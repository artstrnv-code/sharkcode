MATCH/CASE

В Python кроме if относительно недавно появился match/case. Удобная штука вместо длинного if/elif/else.

match var:
    case 0:
        print(0)
    case 1:
        print(999)
    case _:
        print("Sorry")

Что же делает этот код? Берёт объект var и сопоставляет его с вариантами. Если 0 — одно действие, если 1 — другое. case _ покрывает остальные варианты (почти как else).

Но есть и другие фишки. Например, дополнительная проверка:

match var:
    case 0 if count > 1:
        print("Первый вариант")
    case 0 if count <= 1:
        print("Второй вариант")

Полезно, да? Ты ещё не слышал о распаковке!

Представь, что у тебя коллекция из нескольких элементов. Обычным if/else проверять её — вечность:

if mass[0] == 1 and mass[1] == 0 and ...

Бр-р-р, даже дописывать не хочется! match позволяет так:

match collection:
    case (1, 1, 1):
        pass

Такой образец подходит списку или кортежу из трёх единиц. И это ещё можно совмещать с if! Круто, да?

Ещё важно, что здесь для альтернативных образцов вместо обычного or используется |:

match var:
    case 0 | 1:
        print("Ноль или единица")

...И это далеко не всё! Но расскажи я тебе всё, я бы, пожалуй, стал ненужен, ведь ты смог бы и без меня обрабатывать любую ситуацию. Так что просто заинтригую.
