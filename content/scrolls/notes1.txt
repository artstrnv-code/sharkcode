ЗАМЕТКИ №1

1. Всё возвращает какие-то значения

Например:

if a < b:
    ...

На самом деле сначала Python проверяет a < b. Если да — результат сравнения True, иначе False. И if уже смотрит на результат:

if True:
    ...

(Конечно, да: если правда — то правда!)

Точнее, значение получают выражения. if — инструкция, а не выражение.

2. Приоритет операторов

У Python есть одна неявная штука — приоритет операторов. Сначала считается !=, затем and, затем or.

Получается глупая ситуация:

a or b and c or d

Это не то же самое, что (a or b) and (c or d). Python понимает так:

a or (b and c) or d

Можно управлять порядком при помощи скобок, будто это обычная математика. Тогда таких сюрпризов не будет.
