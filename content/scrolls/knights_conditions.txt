Письмо. Условия

Не усложняй условия, рыцарь! Делай их короткими и понятными.

Вместо if a == None: лучше if a is None:.
Но не переусердствуй: is и == — не одно и то же!

== проверяет равенство значений.
is проверяет, являются ли оба имени ссылками на один объект.
Поэтому 7 is 7 — не универсальный способ сравнивать числа.

Вместо if a == True: обычно достаточно if a:.
Вместо if a == False: обычно достаточно if not a:.

    if items:
        print("Not empty")

    if result is None:
        print("No result")

Пустая строка, пустой список и ноль считаются ложными.
Но проверка истинности не всегда заменяет сравнение с True!
Сокращай условия только тогда, когда смысл не меняется.
