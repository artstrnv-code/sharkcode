Переменные могут быть разными:

ЧИСЛОВЫЕ:
• int — целые числа (1, 5, -10)
• float — дробные числа (3.14, 0.5)

ТЕКСТОВЫЕ:
• str — строки ("привет", 'мир')

ЛОГИЧЕСКИЕ:
• bool — True или False.

КОЛЛЕКЦИИ:
• list — изменяемый список [1, 2, 3]
• tuple — неизменяемый список (1, 2, 3)
• dict — словарь {"ключ": "значение"}
• set — множество {1, 2, 3}

Python сам определяет тип:
x = "hi"  → строка
x = 5     → int (тип изменился!)

Можно привести тип вручную:
x = int(3.7)  → 3
