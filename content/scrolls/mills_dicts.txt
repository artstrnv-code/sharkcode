СЛОВАРИ

Представь: тебе надо узнать окончание порядкового числительного на английском. Можно нагромоздить if и elif. Но ленивым пайтон... цам? Истам? Не суть. Есть словари!

numeric_rule = {
    1: "st",
    2: "nd",
    3: "rd"
}

Слева ключ, справа значение. Например, numeric_rule[1] вернёт "st". А numeric_rule[num] найдёт значение по ключу num.

Если вдруг ты подумал, что тебе не хватает элементов в словаре, — вот так можно добавить новые:

numeric_rule[4] = "th"

Немного замысловато, но помни: ключи слева, значения справа.

Теперь там есть ещё пара 4: "th". Если ключ уже существовал, старое значение заменится.

Значения — любые: строки, списки, числа, другие словари. Ключи должны быть подходящими неизменяемыми значениями: числа, строки, кортежи без списков внутри. Например, (1, 2, 3) может быть ключом, а (1, [2, 3]) — нет.

.keys() даёт ключи, .values() — значения, а .items() — пары (ключ, значение). Их удобно распаковывать:

for key, value in numeric_rule.items():
    print(key, value)

А если нужного ключа нет? numeric_rule[99] вызовет ошибку. numeric_rule.get(99, "не найдено") вернёт запасной ответ. Если запасной ответ не указан, .get() вернёт None.
